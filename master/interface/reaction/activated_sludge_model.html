Activated Sludge Model (ASM3h)¶

Group /input/model/unit_XXX(/particle_type_YYY)/phase_reaction_ZZZ/ - TYPE = ACTIVATED_SLUDGE_MODEL3

For information on model equations, refer to Activated Sludge Model (ASM3h).

Notes¶

  • phase_reaction_ZZZ refers to one of the phase-specific reaction groups listed in Reaction models. This model acts on the liquid phase components, so only liquid_reaction_ZZZ is supported; configuring it in a solid phase is rejected.

Warning

When using ASM3h in the liquid phase of a CSTR, the bulk liquid volume must remain constant throughout the simulation. To prescribe this volume, set the CSTR parameter LIQUID_VOLUME. In every section, the inlet flow rate must equal the sum of the outlet and filter flow rates.

Numerical parameters

XH_MIN_THRESHOLD

(Optional) Lower-bound parameter \(c_{X_H,\mathrm{min}}\) for regularizing the heterotrophic biomass concentration. Defaults to \(10^{-6}\).

Unit: Same concentration unit as \(X_H\).

Type: double

Range: finite, > 0

Length: 1

XH_SMOOTH_EPS

(Optional) Smoothing parameter \(\varepsilon_X\) for the lower bound on the heterotrophic biomass concentration. Defaults to \(10^{-4}\).

Unit: Same concentration unit as \(X_H\).

Type: double

Range: finite, > 0

Length: 1

See Activated Sludge Model (ASM3h) for the lower-bound equation.

Environment/process parameters

ASM3_T

Temperature \(T\).

Unit: \(°C\)

Type: double

Range: \(\ge 0\)

Length: 1

ASM3_V

(Optional) Reactor volume \(V\), used by the aeration reaction. Aeration is only active when both ASM3_V and ASM3_IO2 are set; if either is missing, aeration is not considered in the model. The volume is not taken from the unit operation, so it is left to the user to ensure consistency between the volume set here and the unit operation volume.

Unit: \(m^3\)

Type: double

Range: \(\gt 0\)

Length: 1

ASM3_IO2

(Optional) Aeration oxygen input \(iO_2\). If not set, aeration is not considered in the model.

Unit: \(g~O_2~m^{-3}~d^{-1}\)

Type: double

Range: \(\ge 0\)

Length: 1

Stoichiometric parameters

The stoichiometric parameters below are read once at configuration time and built into the stoichiometric matrix. They are not registered as model parameters, so they cannot be changed after configuration and no parameter sensitivities can be computed for them. The kinetic parameters do not have this restriction.

Example

# Setting up an ASM3 reaction in the liquid phase of unit 000, with example values

model.root.input.model.unit_000.nreac_liquid = 1
rxn = model.root.input.model.unit_000.liquid_reaction_000
rxn.type = 'ACTIVATED_SLUDGE_MODEL3'

# Stoichiometric parameters
rxn.asm3_insi = 0.01
rxn.asm3_inss = 0.03
rxn.asm3_inxi = 0.04
rxn.asm3_inxs = 0.03
rxn.asm3_inbm = 0.07
rxn.asm3_ivss_bm = 0.704225352
rxn.asm3_itss_vss_bm = 1.086956522
rxn.asm3_fiss_bm_prod = 1
rxn.asm3_fsi = 0
rxn.asm3_fxi = 0.2
rxn.asm3_yh_aer = 0.8
rxn.asm3_yh_anox = 0.65
rxn.asm3_ysto_aer = 0.8375
rxn.asm3_ysto_anox = 0.7
rxn.asm3_ya = 0.24

# Kinetic parameters
rxn.asm3_kh20 = 9
rxn.asm3_kx = 1
rxn.asm3_ksto20 = 12
rxn.asm3_mu_h20 = 3
rxn.asm3_bh20 = 0.33
rxn.asm3_mu_aut20 = 1.12
rxn.asm3_baut20 = 0.18

# Anoxic reduction factors
rxn.asm3_eta_hno3 = 0.5
rxn.asm3_etah_end = 0.5
rxn.asm3_etan_end = 0.5

# Saturation coefficients
rxn.asm3_kho2 = 0.2
rxn.asm3_khss = 10
rxn.asm3_khno3 = 0.5
rxn.asm3_khnh4 = 0.01
rxn.asm3_khalk = 0.1
rxn.asm3_khsto = 0.1
rxn.asm3_kno2 = 0.5
rxn.asm3_knnh4 = 0.7
rxn.asm3_knalk = 0.5

# Temperature, and the optional aeration
rxn.asm3_t = 12
rxn.asm3_v = 1000.0
rxn.asm3_io2 = 0.0
